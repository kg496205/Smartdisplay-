SmartDisplay 360

SmartDisplay 360 is an ESP32-based smart touchscreen display project. I am building it using an ESP32 DevKit V1 and a 3.5-inch colour TFT resistive touchscreen.

The goal is to create a colourful and interactive dashboard that can display time, date, Bluetooth messages, Wi-Fi status, icons and animations.

I plan to use Arduino IDE for programming and SPI communication to connect the display with the ESP32.

This is my electronics learning project, where I want to improve my skills in microcontrollers, circuit design, programming and hardware development.

Planned features:

- 3.5-inch colour touchscreen
- ESP32 Wi-Fi and Bluetooth
- Digital clock and date
- Custom Bluetooth messages
- Interactive touchscreen menu
- Colourful graphics and animations

More updates, circuit diagrams, code and project photos will be added as development progresses.
